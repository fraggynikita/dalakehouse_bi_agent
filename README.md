Для запуска проекта использовать команду docker compose up -d 

Для начала работы с данными необходимо запустить DAG для загрузки данных с локального хранилища в имитационную OLTP базу load_data_to_oltp. 

После этого можно провести загрузку данных в bronze-слой объектного хранилища с помощью DAG load_data_to_bronze в исходном виде. 

Для загрузки данных в silver-слой используется DAG load_data_to_silver

Для формирования витрин в gold - create_gold_dm
